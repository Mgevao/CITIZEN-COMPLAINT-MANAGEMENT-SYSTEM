
# CITIZEN COMPLAINT MANAGEMENT SYSTEM

## 1. Introduction
The Citizen Complaint Management System is a Python-based
government application developed using Object-Oriented
Programming concepts.

It allows citizens to register complaints about public
services and enables complaints to be searched, displayed
and updated.

## 2. Project Objectives
- Register citizen complaints.
- Generate unique complaint reference numbers.
- Display all complaints.
- Search for individual complaints.
- Update complaint status.
- Demonstrate Python OOP concepts.

## 3. Technologies Used
- Python 3
- Visual Studio Code
- Git and GitHub

## 4. OOP Concepts Applied
- Classes
- Objects
- Constructors
- Attributes
- Instance methods
- Class methods
- Static methods
- Object interaction

## 5. Python Data Structure
A dictionary is used to store multiple complaint objects.
The complaint reference number serves as the dictionary key.

## 6. DPG Standards
- Open-source: Source code is available on GitHub.
- Inclusive: Simple menu-based interface.
- Privacy: Avoids collecting sensitive personal information.
- Modular: Separate classes and functions.

## 7. How to Run
1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run:

python government_complaint_system.py

## 8. Limitations
The application stores records in memory while running.
Records are lost when the application closes.
A future version can introduce permanent database storage.

## 9. Conclusion
The Citizen Complaint Management System demonstrates
how Python Object-Oriented Programming can be used
to solve a real-world government service problem.

It promotes transparency, accountability and improved
communication between citizens and government offices.
